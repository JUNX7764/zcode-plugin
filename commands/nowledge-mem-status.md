description: Check whether Nowledge Mem is reachable from ZCode.
---

Check the Nowledge Mem connection for this ZCode workspace.

1. Use the Nowledge Mem MCP status tool when it is available.
2. If MCP is unavailable, run `nmem --json status`.
3. Report whether local or remote Mem is reachable.
4. Do not print API keys or credentials.
